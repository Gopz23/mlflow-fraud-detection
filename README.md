# mlflow-fraud-detection

## 📌 Overview
This project demonstrates a fraud detection system using Machine Learning and MLflow for experiment tracking and model evaluation.

## 🧠 Features
- Data preprocessing and cleaning
- Random Forest model training
- MLflow experiment tracking
- Logging parameters and metrics
- Model comparison
